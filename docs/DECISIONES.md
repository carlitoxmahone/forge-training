# Decisiones de producto confirmadas

- FORGE se desarrolla primero como web app/PWA.
- Una única carpeta/proyecto maestro.
- Nada de sustituir la carpeta completa por cada cambio.
- Los ejercicios del día aparecen seguidos verticalmente, no en pestañas.
- Un día completo se guarda como una única sesión.
- Las series de calentamiento no cuentan como series efectivas.
- Las series efectivas registran peso, repeticiones y RIR.
- La rutina actual se mantiene separada de la lógica de la aplicación.
- El descanso es configurable y orientativo; no sustituye la recuperación real.
- El proyecto debe funcionar offline cuando esté publicado como PWA.
- Durante Live Server no se usa caché PWA para que los cambios aparezcan al instante.
- GitHub será la fuente de verdad del código cuando se cree el repositorio de FORGE.
